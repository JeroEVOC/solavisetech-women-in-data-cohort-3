# solavisetech-women-in-data-cohort-3
This is a repository of all the projects I've been doing and done through the SWID training - October 2026 Edition

## About the Program
The SolaviseTech Women in Data Cohort 3 program is designed to empower women with practical skills and hands-on experience in data science, analytics, and software development related to data. 

## My Goals & Objectives
By the end of this program, I aim to:
- **Gain More Hands-On Experience:** Work directly with real-world datasets to reinforce and expand my practical technical skills (data analysis / data pipelines / processing workflows).
- **Build Momentum & Re-engage:** Reconnect with an active data community and surround myself with like-minded peers.
- **Expand My Professional Network:** Connect and collaborate with women in data to foster meaningful professional relationships.
- **Develop a Strong Portfolio:** Leverage hands-on projects to build an industry-ready portfolio in preparation for my upcoming career pivot fully into the data field.
